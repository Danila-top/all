# Cross-repository workflow

1. Capture an idea in the scratch repository when it is still experimental.
2. Move stable agent concepts to the agents repository.
3. Move context and memory designs to the context repository.
4. Move integrations and connector patterns to the tools repository.
5. Move ML code and measurements to the experiments repository.
6. Keep long-form source archives in the archival repository.
7. Publish stable presentation material through the HTML site repository.
8. Track the overall map here.
