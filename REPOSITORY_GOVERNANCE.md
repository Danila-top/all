# Repository governance

## Ownership of concerns

Each project repository should have one primary purpose. Large archival artifacts should stay isolated from actively edited code.

## Change discipline

- inspect before editing
- make small changes
- use descriptive commits
- verify writes
- preserve provenance
- never commit secrets

## Logical naming

The GitHub names of some repositories are currently placeholders. Their intended thematic roles are defined in `REPOSITORY_INDEX.md` until repository-name changes are performed through GitHub settings.
